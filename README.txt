Project Description

The Forest Hidden Gems is an interactive platformer game created in Scratch. The player controls a forest explorer who must collect magical crystals while avoiding enemies and dangerous obstacles. The goal of the game is to collect enough crystals to unlock the portal and escape the forest.

The project was created from scratch and focuses on combining creativity, storytelling, coding concepts, and user interaction.

⸻ ⸻ ⸻ ⸻ ⸻ ⸻ ⸻ ⸻ ⸻ ⸻ ⸻ ⸻ ⸻ ⸻ 

How to Play

Click the Green Flag to start the game.
Use the Right Arrow and Left Arrow keys to move the explorer.
Press the Space Bar to jump over mud and hedgehogs.
Collect all five diamonds hidden around the forest.
Avoid touching mud and hedgehogs because they reduce your health.
After collecting all five diamonds, the fairy will appear.
Reach the fairy to complete the game and win.

Game Objectives

The main objective of the game is to collect all required crystals and safely escape the forest.

The player must:

- Explore the environment
- Avoid obstacles
- Defeat challenges
- Collect items
- Reach the final portal

Main character controlled by the player

Collectible item
Five diamonds are hidden throughout the forest
Each collected diamond increases the score
Disappears after being collected

Obstacle drawn using the Scratch Costume Editor
Damages the player when touched
Disappears after being touched
4. Hedgehog
Dangerous obstacle
Damages the player when touched

5. Fairy
Appears after all five diamonds have been collected
Touching the fairy completes the game

Programming Concepts Used
Variables
The following variables were used:
Diamonds – Tracks the number of diamonds collected.
Health – Tracks the player’s remaining health.
Broadcast Messages
Broadcasts were used to control important game events, including:
Victory – Ends the game when the player reaches the fairy.
Game Over – Ends the game when the player’s health reaches zero.
Restart – Resets the game so it can be played again.
Loops
Loops were used for:
Continuous player movement
Collision detection
Checking for collected diamonds
Updating game conditions
Conditional Statements
If and if-else statements were used for:
Detecting collisions with mud and hedgehogs
Collecting diamonds
Checking when all five diamonds have been collected
Determining when the player wins or loses

Sounds Used
Sound effects were added to improve the gameplay experience.
Examples include:
Diamond collection sound
Damage sound when touching obstacles
Victory sound when completing the game
